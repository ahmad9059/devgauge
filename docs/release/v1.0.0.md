## Highlights

- Connect Claude, Codex, Command Code, OpenCode Go, GitHub Copilot, and Antigravity.
- View quota consumption, usage windows, reset times, and provider details.
- Refresh manually, on foreground return, or through Android background scheduling.
- Configure local usage alerts, reset reminders, and quiet hours.
- Keep usage history in encrypted local storage with secure credential handling.
- Choose light or dark appearance and adjust text size.

## Installation

Download **`devgauge-1.0.0-arm64.apk`** below and open it on your Android device. Allow installation from your browser or file manager if prompted.

**Requirements:** Android 7.0 or later and an ARM64 device. The application package is `app.devgauge`.

Preview and development installations are separate. Connect your providers again after installing the release app.

## Verify the download

Download the APK and its `.sha256` file into the same directory, then run:

```sh
sha256sum -c devgauge-1.0.0-arm64.apk.sha256
```

## Usage notes

Provider windows depend on your account plan and the data returned by first-party services. Android background refresh has a six-hour minimum interval and may be deferred by battery or network conditions. Website sign-in sessions can remain after local disconnection or data deletion.

Read the [documentation](https://github.com/ahmad9059/devgauge#readme), [report an issue](https://github.com/ahmad9059/devgauge/issues), or follow the [security policy](https://github.com/ahmad9059/devgauge/security/policy) for private vulnerability reports.
