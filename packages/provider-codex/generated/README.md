# Codex generated-contract manifest

The manifest records the deterministic aggregate hash of all TypeScript and JSON Schema files generated by `codex-cli 0.153.4`. CI regenerates the files from the pinned binary and rejects an aggregate hash change. Generated output is not committed because version `0.153.4` emits 1,010 files (about 7 MB); reviewed runtime schemas in `src/schema.ts` cover only the account methods DevGauge exposes.
